# Botao Stickman Content Studio v1.0

以中文协助非程序员制作可发布的竖屏视频。用户在2026-11-05明确确认：Pilot 02最终双语版作为后续基准；每条新视频先交付短预览，获批后才制作完整视频。已确定的角色、颜色、声音、字幕和比例不再重复询问。

## 首先读取

- [制作标准](references/production-standard.md)：开始新片或修改画面、配音、字幕时读取。
- [双语字幕预设v1.0](references/bilingual-subtitle-preset-v1.0.md)：用户已批准的默认字幕标准；制作或调整字幕时读取，覆盖旧46/32px配置。
- [制作流程与检查](references/workflow-and-qa.md)：执行、恢复制作及交付时读取。
- [基准记录](assets/baseline.json)：可选的本地历史证据索引，记录已批准作品路径及指纹；对应视频/素材不随Git提供，缺少它们不阻止新片制作，不可拿旧样片代替新成片。
- [角色设计](references/character-design.md)：统一身份、衣色与本主题动作。
- [默认配置](assets/production-defaults.json)和[项目模板](assets/project-template.json)：创建新片时读取，模板不含现成剧情。
- [健康事实核查](references/health-fact-check.md)：涉及健康、营养、产品标签时读取。
- [成片检查清单](references/delivery-checklist.md)：预览与最终交付时执行。
- [辅助工具](references/local-tools.md)：新建独立项目、校验并生成双语ASS/SRT时读取。

本 Skill 位于仓库的 `.agents/skills/botao-stickman-content/`，向上三级为仓库根目录。输出保存到仓库 `autopilot-work/<新片唯一目录>/`，不要覆盖Pilot 01/02。优先使用同目录资产中的统一角色主文件。

## 生产约定

默认约60秒、55–65秒自然节奏、9:16、1080×1920、30fps、普通话女声、中英双语字幕、独立竖版封面与平台文案。资料核实、文案、分镜、翻译和免费本地制作由助手推进。新主题需要新分镜和匹配道具，不照搬鱼油瓶或数字。

使用原作者 `skills/directing-stickman-videos/` 的 B1 Autopilot。读取其SKILL.md及B模式生产、运行和质量说明；本项目明确批准的Cute角色、浅黄色背景、配音和字幕覆盖相应默认值，不改写原作者Skill或渲染器。保留其旁白驱动时间轴、预览审批、缓存和全片检查规则。

免费网页版TTSMaker 204「潇潇」为默认。不要擅自换声、用收费API或安装模型。验证码按当前工具政策交接/确认；临时音频生成后及时下载、校验并存入项目。不存在已验证的无人值守免费TTS接口，不承诺全自动。

新片先准备脚本与科学依据，再制作10–15秒自然完整开场预览，含真实声音、双语字幕和代表动作。预览交付后停在用户审批点；只有用户明确批准当前样片并授权剩余制作后才执行原项目approve/render。重要风格变化或新费用另行批准。不要把本次基准批准当作所有未来样片的批准。

主题足够清楚时，自动完成分析、查证、脚本、分镜、原创道具、免费配音网页操作、渲染与发布文案，不在每个阶段重复征求同一设置。保留用户确认的短预览审批；不可核实的重要事实、实际验证码/权限障碍、新费用或重要变化时明确说明。一次输入主题是助手工作流入口，不代表存在无人值守的TTS或自动推断动作的渲染模型。

安全保留现有作品。仅在独立codex/开发分支维护本Skill及必要配置，不覆盖旧成片/素材，不自动stage或提交；秘密、私人资料、输出MP4及素材压缩包不进入版本库。保留根MIT LICENSE，分发本Skill或原项目代码时携带许可证文本；不把软件许可当作音轨、字体或第三方素材的许可。

交付完整MP4、9:16封面、双语SRT/ASS、项目与素材包，以及视频号/小红书文案和Shorts/IG适配建议。注明技术检查与仍需用户听看确认之处。所有发布由用户操作；不自动发布、不Commit、Push或创建PR。
