# 角色设计标准 v1.0

实际主文件：[character.mjs](../assets/character.mjs)。两条已完成视频使用同一角色几何。头部圆心(400,232)、半径151，设计画布800×1020，脚部约y958；头直径约站立高度1/3，包含头发与否会有差异，不宣称精确比例。

- 固定3根头发、大圆眼白、黑瞳孔、小高光、明显眉毛及可变嘴形；同一片不改变脸型。
- 单线手臂和腿、小椭圆手脚、简洁上衣。默认薄荷绿#A8D9C7；第二条实际使用橙色#F2AD68，已获批可作为衣色变体。主文件内另有#EFB071参考色，不混称两者完全相同。
- compare / think / three / point / explain姿态，surprise / confused / think / explain / smile表情；视线与blink参数可复用。
- 道具与动作按主题编排，保持双臂双腿、不增加残影肢体。举物应手物接触，头眼表情与手势一起传达口播意思。
- 主文件compare自带鱼油瓶绘制；它是鱼油案例实现，不是所有新主题都要拿瓶子。新主题优先复用脸/身体结构，在项目自己的角色副本或独立道具层适配，不改原作者核心。
- 已验证PNG姿态序列约8fps、最终30fps；变化须有语义，不能靠反复眨眼或循环摆手掩盖静态主画面。

封面与正片使用同一套身份；特写与全身可切换，人物占屏尺寸由信息重点决定。不能强行将每个镜头都排成小人加大标题。
