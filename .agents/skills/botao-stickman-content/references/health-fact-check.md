# 健康与营养内容事实核查

开始写稿前将关键判断、单位和例子列为事实表：claim、来源URL/标题、查阅日期、支持段落、是否为推断、稿件用语、验证状态。使用权威原始资料，例如政府健康机构、官方标签、临床指南或原始研究；有时效或不确定的医学内容须实际查阅，不凭旧片推断。

## 规则

- 区分营养成分、作用机制、研究关联、临床效果及个体适用性。不要把关联写成治疗，不给缺乏依据的确定剂量建议。
- 核对每粒/每份、每份粒数、mg/g、总量/有效成分等概念；所有比较须相同口径，计算可复算。
- 假设例子在相关画面持续标注「假设示例」和单位。不要把旧片180/120/300或60元/100元写成市场实测或产品事实。
- 标签含量成本不等同于完整质量或个人适用性；不能推出越高越好、越便宜越好。
- 重要事实无法核实：先寻找替代来源或删除非必要断言。核心论点仍无法验证时说明具体缺口，请用户决定是否调整主题；不可编造。
- 口播、画面公式、英文字幕、封面标题与发布文案的科学含义必须一致。文案可以有好奇心，但不能额外增加疗效、恐吓或产品承诺。
- 默认无商业品牌和未经许可产品图。原图/音乐/TTS/字体许可分别记录；免费不自动等于不限用途。新付费服务先获批。
