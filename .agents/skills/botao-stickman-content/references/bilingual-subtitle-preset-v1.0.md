# Botao Bilingual Subtitle Preset v1.0

用户已批准当前8秒字幕预览；此预设为以后Botao视频默认字幕标准，替代旧46/32px字幕。仅适用于Botao专属制作，不修改原作者B1规则，不自动改动历史视频。

机器配置：[JSON](../assets/botao-bilingual-subtitle-preset-v1.0.json)。以本页和JSON中已验证的数值、排版参数为标准，不依赖参考图片。批准样片只在原制作电脑的`autopilot-work/fish-oil-value-20261105/subtitle-revision-v1/`中，不随GitHub提供，也不是新片运行必需资源。预览SHA256仅作历史证据，不能把后续新片视为已批准。

| 参数 | 中文 | 英文 |
|---|---|---|
| 字体 | Microsoft YaHei | Arial |
| 字号（ASS画布像素） | 78 | 50 |
| 颜色 | #000000 | #505050 |
| 字重 | Bold / ASS -1 | Regular / ASS 0 |
| 对齐 | top-center / ASS 8 | top-center / ASS 8 |
| 定位点 | (540,1660) | (540,1750) |

ASS PlayRes=1080×1920；两行定位点相距90px，不等同于字形间可见空白。示例中文实际字形范围x310–731、y1673–1729，宽422px、高57px。其他文字受字体度量影响，需检查编码帧。

字幕布局区域x45,y1640,w990,h180，左右安全边距45px，底部安全边距约120px。新片画面在此区不得放角色脚、产品、标题或图表；不通过移动/遮盖原画面内容来迁就字幕。字体描边1px浅奶黄#FAF8EE、阴影0，保留批准样片渲染。

中英文各一行优先，数字用阿拉伯数字。按实际渲染宽度检查990px上限，长句按自然语义/语音停顿拆cue，不机械缩字、不截断或溢出。确需多行时重新检查字幕区和避让，不能直接向上侵入画面。字幕纯样式修改优先保留既有文字和时间；SRT不保存字号，ASS及此配置保存视觉标准。

同9:16比例按输出宽/1080统一缩放字号、定位、间距和边距；不同宽高比重新排版，不能拉伸。

使用已有干净动画源（本片output/film.mp4为1080×1680）pad至1080×1920，上80下160，再清除旧中文字幕带`drawbox=x=0:y=1640:w=iw:h=180:color=0xFAF8EE:t=fill`，最后用libass绘制双语；不要在旧双语成片上叠加。该遮罩仅在确认没有其他画面内容时可复用。复用音轨`-c:a copy`，不改口播和时长；默认H264 CRF18。

每条新片仍交10–15秒带声音和双语字幕的预览，获批后完整制作。字幕调整先交5–10秒预览；本预设批准不能替代新片审批。
